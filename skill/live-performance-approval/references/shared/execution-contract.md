# Execution and recovery

## Evidence and routing

The project master records each important value with its source file/page, extraction method, verification status, and unresolved conflicts. Read a compact context pack when it saves repeated work; return to the source for uncertain or high-impact fields. Do not rerun all OCR or read every reference for a one-file change.

Classify from actual on-stage performers. `auto` remains unresolved and blocks generation/upload readiness. Domestic and foreign use the same configured applicant, with independent authority, portal, dates, materials and venue roles.

## Applicant changes

`applicant_policy.company_key` selects one company for both branches. Each branch's `applicant_company_key` must equal it. Validate company name, license, address, seal and business-license references against this configuration. Example values fail real initialization.

Existing masters need policy validation before generation. Where the migration helper supports their schema, explicitly run `applicant_policy.py --migrate`; it backs up the master, records the former subject, marks outputs stale, and revokes readiness. Unsupported historical schemas must be mapped from their actual fields first. Never silently rewrite signed or sealed files; list documents that need reissue or renewed signatures.

## Incremental work

Track source content hashes plus the template, configuration and generator inputs. Changed or removed evidence must invalidate the inventory and dependent outputs. Size/mtime can triage large media; use SHA-256 for final upload identity.

Dependencies include: applicant → applicant-named/sealed materials and upload handoff; performers → total rosters and consent/authorization; program → lyrics and media names; embedded program PDF → combined lyrics PDF; template/font/seal → affected rendered files. Resume only outputs whose inputs and verification remain current.

## Completion

Report material completeness, visual QA, and portal state separately. A partial file run does not imply a complete package. Automated QA checks measurable invariants; page inspection and signature provenance remain separate. Preserve the user's requested scope and existing authorization.
