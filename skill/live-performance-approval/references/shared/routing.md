# Approval Routing

Classify the project before generating documents.

## Domestic

Use the domestic workflow only when every on-stage performer is a mainland Chinese performer and the identity materials are mainland resident ID cards.

## Foreign / HK / Macau / Taiwan

Use the foreign workflow when any on-stage performer has one of these materials:

- foreign passport
- Taiwan resident mainland travel permit
- Hong Kong or Macau resident mainland travel permit
- foreign, Hong Kong, Macau, or Taiwan nationality/region in the performer list

## Staff Exclusion

Exclude non-performing staff from performer lists, including sound engineers, lighting staff, photographers, drivers, tour managers, and crew unless the user explicitly confirms that they perform on stage.

## Missing Media

- Domestic: report missing required videos. Remove a song and renumber dependent files only when the user has authorized that policy.
- Foreign: all songs need audio; video coverage is per act. Report missing audio; remove songs only under an applicable user instruction.
