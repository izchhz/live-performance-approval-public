# 国内与涉外分支隔离表

| 项目 | 国内报批 | 涉外/涉港澳台报批 |
|---|---|---|
| 网站 | 浙江政务服务网 `recept.zjzwfw.gov.cn` | 文化和旅游市场企业端 `whsq.mr.mct.gov.cn` |
| 目标页面 | “举办内地文艺表演团体、个人参加的营业性演出审批” | “营业性演出（涉外/涉港澳台）” |
| 演员范围 | 全部为中国内地人员 | 含外国、港澳台人员；混合项目也走此分支 |
| 运行时门禁 | 每次会话核对 host、事项、目标草稿及网页“申报单位”全称 | 每次会话核对 host、业务、目标草稿及实际申报主体；表单未显示时查企业信息/草稿详情 |
| 主体/场地 | 主体使用统一配置；场地运营方和实际场所按正文分别核对 | 同一统一主体；场地材料权属与实际场所按涉外项目正文核对 |
| 日期 | 演出计划填写开始/结束日期和场次数；无入出境日期 | 演出起止日期；项目默认入境首演前 10 天、出境末演后 10 天，明确材料日期优先；场次含具体时间 |
| 节目名称 | 复制节目单整格，训练格式含书名号、译名和演员名单 | 复制歌名原文，不含文件序号 |
| 单曲附件 | 每首一个匹配视频 | 每首歌词 DOCX、音频 MP3；指定歌曲另有视频 MP4 |
| 总歌词 | “上传材料”页统一上传一次 DOCX | 只在第一首节目窗口上传一次；其余节目不传 |
| 全局材料页 | 有：申请表、节目单、演员名单、主体许可证、歌词、经办人材料、授权委托书 | 无国内式全局材料页；附件分布在演员、节目、场所窗口 |
| 无最终提交授权时的停止点 | 取件方式/信息确认/最终提交前 | “确认以上承诺”与最终提交前 |

两边的 `ready_for_upload` 都只对当前浏览器会话和当前草稿有效；重新登录、换账号、换事项或换草稿必须重置并重新核验。

任何一行出现交叉（例如国内页面要求入出境日期、涉外节目名称包含国内整格演员名单、在涉外页面寻找国内材料槽位）都视为路由错误，立即停止。
