# Agent 执行手册

本文档给使用该 skill 的 AI agent 阅读。

## 必须先做

1. 读取 `skill/live-performance-approval/SKILL.md`。
2. 读取 `references/shared/project-structure.md`。
3. 读取 `references/shared/configuration.md`。
4. 读取 `references/shared/routing.md`。
5. 先列出源资料文件夹内容，不要直接开始生成。
6. 生成或更新项目主档后，再开始制作文件。

## 决策点

- 任意演员为外国、香港、澳门、台湾身份时，进入涉外/港澳台流程。
- 文件字段要求填写演员时，填写真实上台演员姓名，不填写乐队名。
- 国内 `00` 号申请表和正式表格必须使用训练好的 Word 模板，不能手动画表、重排版式或简化字段。
- 国内 `00/01/02/03/04/08` 使用所有实际上台人员；`05/06/07` 使用每首歌实际参与人员。只有部分人参与的曲目必须写入提醒清单。
- 如果某首歌缺少必要音频或视频，按规则从曲目单和歌词中删除并重新排序。
- 需要翻译时，维护一份统一翻译表，演出名、歌名、歌词、媒体文件名全部复用同一译法。
- 国内授权委托书、核验文字、授权人签名等字段必须来自私有配置，不得在公开包中硬编码真实姓名。
- 生成提供人、核验文字或签名之前，先检查配置字体是否覆盖全部字形；出现方框、缺字、裁切或溢出时停止交付。
- 涉外拼盘项目的视频数量按乐队/艺人组合分别计算，每个乐队通常需要 1-2 首视频。
- 涉外护照信息需要先按 ICAO Doc 9303 TD3 MRZ 校验护照号、出生日期、有效期等字段；MRZ 缺失、裁切、模糊或校验失败时必须提醒人工复核。
- 港澳台证件如存在 MRZ，也需要优先用 MRZ 提取和核对信息；已测试台湾通行证三行 MRZ 可校验通行证号、有效期和出生日期。
- 先完成证件 OCR、MRZ 校验和异常提醒，再生成 01/02/03/04 等依赖演员身份信息的文件。
- 涉外歌词标题只保留序号和歌名，不在歌曲标题后追加演员名单或成员名单。
- 涉外艺人证件扫描件 Word 页面内只放证件图像本身，不额外添加文本姓名、标题或说明。
- 涉外艺人同意函的模拟签名按姓名文字系统分开处理：英文/拉丁姓名用英文签名字体，中文姓名用中文手写体；真实签名优先。

## 输出规则

- 正式材料放入 `03_最终提交材料`。
- 中间文件、脚本、渲染预览、临时转换文件放入 `02_生成中间文件`。
- 缺失资料、证件异常、音视频不一致、内容修改记录放入 `04_缺失资料与提醒`。
- 不删除、不覆盖用户提供的唯一原始资料。

## 需要停止并提醒的情况

遇到以下情况时，停止继续生成并明确提醒使用者：

- 必需 Word 模板缺失。
- 证件扫描件不完整或无法辨认。
- 中国居民身份证校验码失败。
- `00` 号申请表或其他正式模板被错误重排、表格尺寸明显变化。
- 提供人、核验文字、授权签名出现字体方框、缺字、裁切或溢出。
- 护照或通行证有效期无法识别，或证件 MRZ 缺失、裁切、模糊、校验失败。
- 涉外拼盘中某个乐队没有达到视频材料数量要求。
- 生成后的 DOCX/PDF 有页面溢出、页数错误或明显排版异常。
- 公开分支中出现真实公司信息、公章、证件或私人信息。
