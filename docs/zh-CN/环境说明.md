# 环境说明

## 必需系统工具

- Python 3.10+
- LibreOffice
- ffmpeg
- ffprobe
- Poppler 工具，常用于 PDF 预览转换，例如 `pdfinfo`、`pdftoppm`

macOS 可以用 Homebrew 安装部分依赖：

```bash
brew install ffmpeg poppler
```

LibreOffice 建议使用官方安装包或系统包管理器安装。

## Python 依赖

```bash
python3 -m pip install python-docx Pillow pypdf reportlab PyYAML
```

可选依赖，根据 OCR、繁简转换或翻译流程决定：

```bash
python3 -m pip install pymupdf pytesseract opencc
```

## 字体

- 中文政府类公文建议使用宋体或宋体风格字体。
- 提供人手写标注需要本机安装可用的中文手写字体。
- 艺人签名优先使用真实签名图片；没有真实签名时，再使用本机不同的手写或签名字体生成。
