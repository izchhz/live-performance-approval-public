# 环境说明

## 必需系统工具

- Python 3.10+
- LibreOffice
- ffmpeg
- ffprobe
- Poppler 工具，常用于 PDF 预览转换，例如 `pdfinfo`、`pdftoppm`

macOS 可以用 Homebrew 安装部分依赖：

```bash
brew install ffmpeg poppler
```

LibreOffice 建议使用官方安装包或系统包管理器安装。

## Python 依赖

```bash
python3 -m pip install python-docx Pillow pypdf reportlab PyYAML fonttools
```

可选依赖，根据 OCR、繁简转换或翻译流程决定：

```bash
python3 -m pip install pymupdf pytesseract opencc
```

## 本地中国身份证 OCR

用于在本机识别中国居民身份证图片，减少 agent 逐张查看身份证原图。Apple Silicon Mac 可使用 PaddlePaddle 官方 CPU 包：

```bash
python3 -m pip install paddlepaddle==3.3.0 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
python3 -m pip install paddleocr
```

运行：

```bash
python3 skill/live-performance-approval/scripts/scan_cn_id_ocr.py \
  --project-dir <项目目录> \
  --source-dir <素材目录>
```

第一次运行会下载 OCR 模型到 `~/.paddlex/official_models/`，后续会使用本地缓存。

## 本地护照 / 港澳台证件 MRZ

用于本地提取护照和港澳台证件机读码：

```bash
brew install tesseract
python3 -m pip install --user PassportEye
```

运行：

```bash
python3 skill/live-performance-approval/scripts/scan_passport_mrz.py \
  --project-dir <项目目录> \
  --source-dir <素材目录>
```

也可以通过上下文包脚本统一执行：

```bash
  --project-dir <项目目录> \
  --source-dir <素材目录> \
  --extract-text \
  --scan-cn-id \
  --scan-mrz
```

## 字体

公开版默认不打包手写字体文件，因为很多中文手写体、签名字体属于商业字体，不能直接发布到 GitHub。

推荐配置：

- 中文政府类公文：使用运行机器上已有的宋体或宋体风格字体，例如 SimSun、宋体、Songti SC、Noto Serif CJK SC、思源宋体。
- 中文“提供人”手写标注：本机安装至少一种有授权的中文手写字体。商业字体请保存在公开仓库之外。
- 中文艺人签名：优先使用真实签名图片。没有真实签名时，安装多种有授权的中文手写字体，并按艺人轮换；如果字体显示方框、过于印刷体、过于整齐，需要换字体。
- 英文或外籍艺人签名：本机安装至少一种有授权的英文 signature 风格字体，或优先使用真实签名图片。
- 固定手写信息、核验文字和授权签名导出前，需要用 `fontTools` 检查字体是否覆盖全部字符；出现方框、缺字、裁切或溢出时，不应交付最终 PDF。
- 如果文字直接嵌入 PDF 时仍出现方框，可在私有运行环境中把已验证字体渲染成透明 PNG 后叠加到文档，但仍要保留页面几何和公章位置。

公开仓库字体规则：

- 不要提交 `.ttf`、`.otf`、`.ttc`、`.woff`、`.woff2` 字体文件，除非字体许可证明确允许再分发。
- 团队内部已有授权字体时，建议放在私有包或 Git 之外的本机目录，再在运行配置中填写字体名称或路径。
- 字体分类和回退规则见 `skill/live-performance-approval/assets/fonts/README.md`。
