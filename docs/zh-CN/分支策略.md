# 分支策略

建议使用两个独立历史的仓库，而不是同一个仓库的两个分支。

推荐本地结构：

```text
live-performance-approval-private   branch: private-local
live-performance-approval-public    branch: public-github
```

公开仓库不能通过“先提交私密文件、再删除私密文件”的方式生成。Git 会保留历史对象，删除后的文件仍可能从历史中恢复。

## 发布公开 GitHub

1. 只在 `live-performance-approval-public` 中操作。
2. 执行 `docs/zh-CN/公开去敏策略.md` 中的敏感信息扫描。
3. 人工检查所有二进制文件。
4. 只推送 `public-github` 分支，或在干净公开远程中将其重命名为 `main`。

## 私有本地版本

真实模板、公章、公司配置、完成案例应保留在私有仓库或加密存储中，不进入公开仓库历史。
