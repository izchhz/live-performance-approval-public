# 公开去敏策略

公开仓库不得包含：

- 真实公司名称、地址、许可证号、营业执照或资质文件
- 真实公司公章或公章扫描件
- 真实身份证、护照、港澳台通行证、签证
- 手机号、私人地址、经办人真实姓名、法定代表人信息
- 真实签名
- 已完成的报批案例
- 私密歌词、音视频、合同、发票、政府反馈或批文
- 包含以上信息的 Git 历史

## 推荐工作方式

使用两个仓库或两个不共享历史的本地目录：

- 私有仓库或私有分支：保存真实公司资料和公章。
- 公开仓库或公开分支：只保存占位符、流程文档、通用脚本。

不要从私有仓库直接删除敏感文件后推公开版，因为 Git 历史仍可能包含被删除的文件。

## 推送前扫描

在公开仓库根目录执行：

```bash
rg -n "REAL_COMPANY|身份证|护照|公章|营业执照|法定代表|手机号|330101|浙演经|杭州" .
find . -type f \( -name "*.png" -o -name "*.jpg" -o -name "*.jpeg" -o -name "*.pdf" -o -name "*.docx" \) -print
```

命中结果需要人工复核。对于公开仓库，任何真实二进制资料都应删除并确认没有进入 Git 历史。
